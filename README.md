# C++ 实用工具集 (Utility Toolkit)

一个简洁、实用的命令行多功能工具集，集成 **14 种**日常计算与转换功能，适合学习、演示或日常小工具使用。

---

## 🚀 功能一览

所有功能均通过主菜单数字选择（1～14）进入：

1. **四则运算**  
   支持 `+`、`-`、`×`、`÷`，输入格式：`数字 运算符 数字`（用空格隔开）。

2. **进制转换**  
   支持 2～36 进制与十进制互转，10 以上的余数用字母 `A~Z` 表示。

3. **ASCII ↔ 字符互转**  
   可将字符转为 ASCII 码值，或输入码值得到对应字符。

4. **温度转换**  
   实现摄氏度与华氏度的双向转换。

5. **质数判断**  
   判断一个正整数是否为质数（素数）。

6. **字符串反转**  
   将输入的字符串完全反转（如 `hello` → `olleh`）。

7. **大小写转换**  
   将字符串全部转为大写或全部转为小写。

8. **统计字数**  
   统计一段文字的总字符数（含空格），以及不含空格的字符数。

9. **统计单词数**  
   统计英文句子中的单词个数（以空格分隔）。

10. **周长计算**  
    计算矩形的周长（长 + 宽）× 2。

11. **面积计算**  
    计算矩形的面积（长 × 宽）。

12. **体积计算**  
    计算长方体的体积（长 × 宽 × 高）。

13. **判断闰年**  
    输入年份，判断该年是否为闰年（满足能被 400 整除，或能被 4 整除但不能被 100 整除）。

14. **退出**  
    输入 `14` 即可结束程序。
